# Sema viewing

Sema lets viewers choose how much visual description they hear and revisit visual moments while watching a film.

## Language

**Playback session**:
A viewer's time with one selected film, including playing, pausing, revisiting and resuming. It ends when the viewer leaves that film.
_Avoid_: Viewing transaction

**Visual moment**:
An event visible in the film that can be described once the viewer reaches it.
_Avoid_: Scene, when referring to a single event

**Revisit**:
Hearing a visual moment described while the film waits. The moment must already be available at the current playback position.
_Avoid_: Rewind, recap

**Critical description**:
A description carrying a required story fact. If interrupted, it remains available until heard or deliberately skipped.
_Avoid_: Essential description, when referring to a required fact rather than the chosen detail level

**Reveal time**: The earliest film time at which a visual moment may be described.

**Missed description**: An important description that was interrupted before completion and remains available to hear again.

**Earlier moment**: The next older visual moment relative to the last requested description, or the moment Revisit would currently choose.

**Moment range**: A time-ordered group of already-revealed visual moments used to narrow a browsing choice. It does not imply a narrative chapter.

**Moment picker**: A choice of ranges and named moments that lets the viewer request a description without stepping through every intervening moment.
